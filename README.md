# Fórmula+

Aplicação web para apoiar a gestão de uma farmácia de manipulação, organizando fórmulas, matérias-primas, estoque, usuários e etapas operacionais.

## Funcionalidades

- Cadastro e acompanhamento de fórmulas magistrais.
- Gestão de matérias-primas, lotes e estoque.
- Fluxo de trabalho da cotação à entrega, com etapas de pesagem e controle de qualidade.
- Perfis de acesso para administração e operação.
- Registro de auditoria para operações relevantes.

## Tecnologias

- Backend: ASP.NET Core e .NET 10.
- Frontend: Angular.
- Persistência: PostgreSQL; SQLite para desenvolvimento local.
- Execução: Docker Compose.

## Sobre este repositório

Este é somente um espaço de apresentação: não contém o código-fonte da aplicação, configuração de produção, credenciais, banco de dados ou dados de pacientes. O repositório de desenvolvimento permanece privado.

Não há uma demonstração hospedada neste repositório. As informações aqui são descritivas e não incluem dados reais de usuários ou clientes.
